# Elemetry · Project Fiki

Documentatia proiectului Software Engineering, 2026–2027. O singura pagina, in romana fara diacritice, cu descrierea proiectului M1 si jurnal pentru etapele viitoare.

**Site public:** https://andreiasm5.github.io/elemetry-fiki/

- Andrei Ivascu — cofondator; tehnologie & dezvoltare (rol propus)
- Diana Ciociou — cofondatoare; produs, UX & validare (rol propus)

## Continut

M1 include toate cele zece cerinte: titlu, echipa (fotografii, roluri, emailuri), problema, solutie, clienti, competitie, diferentiere, metrici, costuri si venituri. M2–M9 si M11 sunt marcate explicit drept etape viitoare.

Graficul din introducere este o ilustratie interactiva cu date simulate. Nu reprezinta un produs functional sau rezultate masurate. Preturile, economiile si avantajele competitive nu sunt prezentate drept validate.

## Editare

- `index.html`: textul, echipa, linkurile si milestone-urile
- `style.css`: culori, fonturi si responsive layout
- `script.js`: scenariul ilustrativ, progresul lecturii si navigarea
- `assets/`: fotografii si simbolul Elemetry

Nu necesita instalare sau build. Pentru preview local cu Node: `node serve.mjs` (serverul este doar pentru dezvoltare). GitHub Pages serveste fisierele din radacina branch-ului `main`.

Adaugati livrabilele milestone-urilor pe aceeasi pagina si schimbati statusul numai dupa realizarea lor. Actualizati data ultimei modificari.
